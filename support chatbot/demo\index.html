🚀 Integration & Module Highlights

Independent Module Architecture:
This chatbot operates as an isolated component with clean decoupling between:
• Core Engine: State machine, bilingial tokenizer & fuzzy matcher.
• i18n Engine: Dynamic English & Hindi localization.
• REST API & WSGI/ASGI: Plug-and-play into any Python or cloud backend.
• Web Widget / SDK: Zero-dependency vanilla JS & Web Component.
